# Contributing

Thanks for your interest. Outside pull requests are not merged for now, because the project has no contributor terms yet. Until there are, please:

- Report bugs and ideas as GitHub issues, with synthetic logs only (never real logs, secrets or internal names).
- Report security problems privately, as described in [SECURITY.md](SECURITY.md).
